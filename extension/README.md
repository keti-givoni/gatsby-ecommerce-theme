# תוסף כרום: התאמת לבוש לפודקאסט

תוסף דפדפן (Manifest V3) שמזהה כשצופה פותח פרק של הפודקאסט ביוטיוב, ומציע לו לעבור לגרסה של הפרק עם לבוש מותאם לסגנון הצפייה שלו (חסידי, ליטאי, דתי לאומי, מסורתי).

התוסף **לא משנה את הסרטון ביוטיוב**. הוא רק מזהה את הפרק ומקשר לגרסה המותאמת שמתארחת בפלטפורמה שלך, מאחורי המנוי.

## התקנה לבדיקה

1. פותחים בכרום את `chrome://extensions`
2. מדליקים "מצב מפתח" (Developer mode) בפינה
3. לוחצים "טען תוסף לא ארוז" (Load unpacked) ובוחרים את התיקייה `extension`
4. פותחים כל סרטון ביוטיוב. בפינה הימנית העליונה יופיע כרטיס ההצעה.

כל עוד לא הוגדרה כתובת פלטפורמה, התוסף עובד **במצב דמו**: כל סרטון ביוטיוב נחשב פרק, והקישורים מובילים לכתובת דוגמה. זה מאפשר לראות את החוויה לפני שיש פלטפורמה.

## מה יש בתוסף

| קובץ | תפקיד |
|---|---|
| `manifest.json` | הגדרות התוסף והרשאות |
| `content.js` | רץ בתוך יוטיוב, מזהה פרק ומציג את הכרטיס |
| `background.js` | פונה ל-API של הפלטפורמה ושומר תשובות במטמון |
| `popup.html/js` | החלון שנפתח בלחיצה על אייקון התוסף |
| `options.html/js` | דף הגדרות: כתובת הפלטפורמה, סגנון מועדף, מעבר אוטומטי |
| `common.js` | רשימת הסגנונות והגדרות ברירת מחדל, משותף לכולם |

## הגדרות למשתמש

- **סגנון הצפייה שלי**: הסגנון שיודגש ראשון בכרטיס.
- **מעבר אוטומטי**: אם מסומן ויש לפרק גרסה בסגנון המועדף, התוסף עוצר את הסרטון ביוטיוב ועובר ישר לגרסה המותאמת. לא פעיל במצב דמו.
- **כתובת הפלטפורמה**: הכתובת של האתר שלך. בשמירה כרום יבקש אישור גישה לדומיין.

## מה הפלטפורמה צריכה לספק

התוסף פונה לכתובת אחת בלבד:

```
GET <כתובת הפלטפורמה>/api/episodes/by-youtube/<מזהה סרטון יוטיוב>
```

תשובה כשהסרטון הוא פרק (HTTP 200):

```json
{
  "title": "פרק 12: השם של הפרק",
  "versions": [
    { "style": "hasidic",    "label": "חסידי",      "url": "https://app.example.com/watch/ep-12?style=hasidic" },
    { "style": "dati_leumi", "label": "דתי לאומי",  "url": "https://app.example.com/watch/ep-12?style=dati_leumi" }
  ]
}
```

תשובה כשהסרטון אינו פרק: HTTP 404.

הערות:

- `style` צריך להתאים למזהים ב-`common.js` כדי שהעדפת המשתמש תעבוד. אפשר להחזיר רק חלק מהסגנונות לכל פרק.
- `label` אופציונלי. אם חסר, התוסף משתמש בשם מהרשימה שלו.
- הכתובת ב-`url` היא של הפלטפורמה. בדיקת המנוי והתשלום נעשית שם, לא בתוסף.
- אם המשתמש לא אישר גישה לדומיין בהגדרות, ה-API חייב להחזיר `Access-Control-Allow-Origin: *` על הנתיב הזה.
- התשובות נשמרות במטמון ל-10 דקות.

## הוספה או שינוי של סגנונות

עורכים את הרשימה `STYLES` ב-`common.js`. המזהה (`id`) הוא מה שהפלטפורמה מחזירה בשדה `style`, והשם (`label`) הוא מה שמוצג למשתמש.

## מגבלות

- עובד רק בכרום (ובדפדפנים מבוססי Chromium) במחשב. באפליקציית יוטיוב בטלפון אין אפשרות לתוספים.
- התוסף אינו מזהה מנוי. את הגבלת הצפייה למנויים עושה הפלטפורמה.

## בדיקה אוטומטית

הבדיקה מריצה את התוסף בכרומיום מול דף מדומה של יוטיוב (בלי רשת) ובודקת: הצגת הכרטיס, פתיחת גרסה ועצירת הסרטון, סגירה, ניווט בין סרטונים, העדפת סגנון, ודף הפופאפ.

```
npm install -g playwright   # פעם אחת
NODE_PATH="$(npm root -g)" node extension/test/test-ext.js
```
